# Skill: Task Decomposition (Atlas)

- Prefer 2-4 tasks in this order: (1) optional analyze/plan task when the goal
  needs decisions, (2) the main chapter write, (3) bible/outline sync only if
  the goal changes established facts.
- One chapter task = one chapter. "Write 3 chapters" → three sequential
  chapter tasks, each naming its target chapter number.
- A chapter task's detail MUST carry: target chapter number, the beats/scenes
  to cover (taken from the outline snapshot), a length hint (words), and
  continuity anchors (how the previous chapter ends, relevant facts/ledger).
- Never plan: direct database edits outside the tool set, sediment runs,
  review rounds, or export steps — the runtime owns those.
