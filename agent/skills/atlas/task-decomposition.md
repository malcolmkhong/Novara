# Skill: Task Decomposition (Atlas)

- Prefer 2-4 orders in this order: (1) optional nova research when the goal
  needs bible answers, (2) the main chapter write (sage), (3) a prism review
  of the written chapter when the goal expects quality checks, (4) bible/
  outline sync only if the goal changes established facts.
- One chapter order = one chapter. "Write 3 chapters" → three sequential
  chapter orders, each naming its target chapter number.
- A chapter order's detail MUST carry: target chapter number, the beats/
  scenes to cover (taken from the outline snapshot), a length hint (words),
  and continuity anchors (how the previous chapter ends, relevant facts/
  ledger).
- Never dispatch: direct database edits outside the tool set, sediment
  runs, or export steps — the runtime owns those (a forge export only when
  the goal explicitly asks for a manuscript build).
