# Skill: Ground-Truth Reporting (Atlas)

- Plan against the story snapshot ONLY. Cite chapter numbers that exist in it.
- If the goal conflicts with established facts (bible, outline, open
  foreshadow ledger), plan the reconciliation FIRST and say so in `notes`.
- Never promise word counts you cannot derive from the snapshot's quota
  section; the runtime assigns chapter quotas, tasks only carry the hint.
- If the goal is already satisfied by existing chapters (nothing to write),
  plan zero chapter tasks and explain in `notes` instead of inventing work.
