# Skill: Prose Craft (Sage)

Apply WHILE drafting — write it right the first time.

## Show, never label
- Never name an emotion ("他感到愤怒"). Externalize via reaction +
  micro-action ("指节捏得发白。他把杯子放下，才开口。").
- Cut filter words on sight: 感到 / 觉得 / 意识到 / 仿佛 / 似乎.
- After an action beat, never explain it. "她摔上门。" — stop there.

## Dialogue carries the scene
- Every exchange has an intent under the words — probe, pressure, dodge,
  lure; characters deflect, interrupt, or misaim.
- Distinct voice per recurring character: vocabulary, sentence length, one
  habit; the brief's voice notes bind.
- Action beats over speech verbs; cap "说道/淡淡道" tags at ~30%; no adverb
  tags ("缓缓说道") — precede with action.

## Suppress AI habits
- No self-closing paragraph (cause→process→result→lesson): cut the lesson.
- No time-skip narration ("不知不觉"); cut to the next scene.
- Vary paragraph length hard; uniform paragraphs are a machine signature.
- Ban stock reactions ("瞳孔微缩" / "眸中闪过一丝X"); invent one that fits
  THIS character.
- No meta-scaffolding ("总而言之") in fiction.

## POV & grounding
- One viewpoint per scene; never hop heads; follow the brief's named POV.
- Anchor each new scene with one sensory detail before dialogue.
