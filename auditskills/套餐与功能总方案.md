## 0. 结论先行

```
Free $0 ─ Author $19 ─ Studio $49 ─ Autopilot $99 ─ Showrunner $199   （均为月费）
└────── Copilot：人写，AI 辅助 ──────┘   └──── Outcome：人定方向，AI 交付成品 ────┘
每档 = 功能解锁 + 月度积分额度；所有付费档可加购积分包（buy credits）
补充入口：单次购买 $119/本、$229/部（高于月费 20%，引导订阅）
```

1. **定价不变量：每笔收入对应有界成本单元。** 月费含固定积分额度 → 成本天花板 = 额度 × $0.001（1 credit = $0.001 是代码已实现的精确锚定）；超量用户买积分包（售价 1.4–1.8× 成本），每一层都盈利。唯一要排除的形态是"无封顶月费"。
2. **$10 成本 → $99 收入靠分角色模型路由**：正文用贵模型保质量，评审/记忆/规划用便宜模型。一本 14 万字小说估算成本 ≈$7（含重试余量 ≈$9.8），落在 Autopilot 12,000 积分额度内。
3. **月费+积分的三重利润**：保底毛利 87–88%（额度封顶）+ breakage 纯利（月度额度不结转）+ 超量包扩张毛利 29–44%。
4. **功能分层卖"保护等级与交付能力"**，不卖"存储位置"（免费稿件也在云端，纯云架构是事实）；机制性细节进对比表，结果型价值上卡片。
5. **红线：未实现的功能不上定价页**（§6 承诺核对表逐条把关）。

### E. 高阶交付管线（Autopilot / Showrunner 专属）

**#21 全自动成书管线（Autopilot $99/月）**

用户旅程：
```
① 书名/一句话创意 → ② AI Q&A 向导 5–8 轮（类型/基调/主角/世界观/
冲突/结局/禁忌/字数）→ ③ 创作合同+分卷大纲，用户确认"项目章程"
→ ④ 全自动逐章：写作→评审→定稿→记忆投影，循环至完本
→ ⑤ 每 ~10 章里程碑通知（可中途干预/叫停）→ ⑥ 交付
```

交付规格（可验收承诺）：
| 项 | 规格 |
|---|---|
| 字数 | 140,000 字 ±10%（服务端 countWords，不可伪造） |
| 结构 | 45–50 章，分卷大纲，首尾完整 |
| 一致性 | 全章通过评审门禁；doctor 无 critical |
| 记忆 | 角色状态/伏笔/事实全程携带 + 伏笔回收清单 |
| 格式 | Markdown + DOCX + JSON 备份 + 一致性报告 + 创作过程档案 |
| 返修 | 门禁未过章节免费重写；完稿 7 天内 1 次整体修订轮 |
| 额度 | 月含 12,000 积分 ≈ 1 本（典型消耗 7,000–10,000）；第二本买积分包 |
| 时限 | 48–72h 完稿（离峰排队，待拍板） |

基础【已实现】：wizard Q&A、合同、五角色 runtime、full_access、审批纯 HTTP、resume、doctor、记忆投影、导出。
缺口【需建设】：项目章程预授权（不破坏 write-gate 铁律：章程内新建不暂停，覆写已有正文仍暂停）；章节级检查点编排器+自动续跑（Cloud Run 300s 限制）；项目积分闸+触顶暂停；里程碑通知。工程量 L。

**#22 漫剧制作包管线（Showrunner $199/月）**

定位：漫剧/短剧市场买的是可开拍的剧本资产。人工外包整部剧本成本远高于 $199（定性判断，⚠️市场价需调研后作销售锚点）。独有优势：改编从记忆库取正典（角色/事件/时间线/伏笔已结构化），不是从零读文本——"带记忆的改编"通用 AI 做不到。

## 4. 成本模型（可复算）

### 4.1 token 账：一本 14 万字小说

依据（项目真实预算参数）：47 章 ×3,000 字；chapterContextChars=24,000；sedimentWindow=4,000/overlap 800；repairRounds≤2（假设 30% 章节返修 1 次）；中文 1 字 ≈0.7–1.2 token（⚠️须实测 tokenizer 校准）。

| 环节 | 输入 tokens/章 | 输出 tokens/章 |
|---|---|---|
| 草稿（Sage） | 20k–30k | 2.5k–4k |
| 评审（Prism） | 10k–15k | 1k–2k |
| 记忆提取（Nova） | 4k–6k | ~1k |
| 规划摊销（Atlas） | ~5k | ~0.5k |
| 返修期望 | +30% 草稿项 | +30% |
| **合计** | **~50k–65k** | **~5k–8k** |

全书取整：**输入 3M / 输出 400k**（含返修与重试余量）。

### 4.2 路由策略成本（registry 单价，UNVERIFIED）

`成本 = 输入M数 × inputUsdPer1M + 输出M数 × outputUsdPer1M`

| 策略 | 草稿模型 | 辅助模型 | 全书成本 |
|---|---|---|---|
| A 全便宜 | $0.15/$0.60 | 同左 | ≈$0.69（prose 质量会塌，不采纳） |
| B 全中档 | $0.55/$2.19 | 同左 | ≈$2.53 |
| C 全贵档 | $3.00/$15.00 | 同左 | ≈$15.00 |
| **D 混合路由（推荐）** | $3.00/$15.00 | $0.15/$0.60 | **≈$7.0**（×1.4 余量 ≈**$9.8**） |

策略 D = 草稿(1.2M入/0.2M出)×贵 + 辅助(1.8M入/0.2M出)×便宜。**省成本不能省在用户直接感知的正文上。**
Showrunner 改编增量：输入 1.5M–2M / 输出 120k–160k，混合路由 ≈$4–7；$199 档典型总成本 ≈$11–22。

### 4.3 成本硬上限（积分闸 = 美元闸，精确）

| 单元 | 积分上限 | 成本天花板 | 触顶行为 |
|---|---|---|---|
| Autopilot 月度额度 | 12,000 | $12 | 暂停+通知：买包续跑 / 等下月 / 系统性超支走质量基金 |
| Showrunner 月度额度 | 25,000 | $25 | 同上 |
| 单次购买 | 30,000/本、45,000/部 | $30/$45 | 暂停+加购或按进度退款 |

### 4.4 六个降本杠杆（不牺牲正文质量）

1. 分角色模型路由（最大杠杆，省 ~50% vs 全贵档；router.ts 已支持多供应商）
2. 上下文切片复用（snapshot-slice 已有，评审/记忆读切片）
3. 返修预算（单章 ≤2 轮；全书返修率 >30% 触发人工介入）
4. 缓存折扣不计入定价（pricing.ts 诚实规则：成本按上界算，缓存节省是纯利润余量）
5. 便宜模型做结构化任务（台账/伏笔/时间线是抽取分类，$0.15 档足够）
6. 离峰排队（Autopilot 非实时交付，与交互用户错峰）

| 积分包 | $9/$15/$49 | 满耗 $5/$10/$35 | 同左 | — | 29–44% |
| 单次购买 | $119/$229 | $5–22 | $30/$45 | ~90% | ≥75%/≥77% |

**规模示例（100 个 Autopilot 订阅/月）**：MRR $9,900；典型成本 $800 → 毛利 $9,100；人人满耗（病态）成本 ≤$1,200 → 毛利仍 ≥$8,700；积分包扩张收入另叠（月写两本的用户买 $15 包，平台再赚 $5–7）。

**滥用不是风险是收入**：积分经济下批量生成者每本书都付钱——转售者是客户，不是漏洞。

## 9. 红线备忘

1. 免费稿件也在云端——分层卖"保护等级"，不卖"存储位置"；不做"免费只存 local"的架构倒退。
2. 诊断遥测必须 opt-in、只传元数据、公开采集清单；默认不碰稿件内容。
3. 存证话术 = 创作时间证明，不宣称法律效力；漫剧销售页注明"用户须对输入创意拥有合法权利"。⚠️版权归属各法域不同，法律结论咨询专业人士。
4. 未实现功能不上定价页（§6 核对表把关）。
5. 无人值守 AI（#16/#21）必须带项目积分闸 + 默认审批策略 + 触顶暂停，绝不静默超支。
6. 套餐价格以服务端配置为准；权益发放只由验签 webhook 或后端查单触发；积分发放与订阅状态同一事务；禁止客户端传金额/积分数。
7. 内容安全：Q&A 阶段即拦截违规题材，全自动管线保留内容红线过滤。
8. 质量承诺可验收化（字数/门禁/doctor 机器可验证），不承诺"文学杰作"。
